Talk your notes onto a PDF.

  1. Open a PDF.
  2. Select a sentence. It highlights, and a note opens beside it — or hit + Add note and click anywhere on the page.
  3. Press the microphone on the note and just talk.
  4. Save annotated PDF — the notes are printed into the page margin, visible without clicking anything.

Your notes are saved inside the PDF, so reopening that file here brings them all back, still editable. Everything stays on this computer — the file is never uploaded anywhere.
